# SOLARIS: your personal AI assistant

Double-click `start_solaris.bat` to run it. The first time, it sets itself up and opens a
settings file: paste your free Gemini key after `GEMINI_API_KEY=`, save, close.

Voice commands you can try (type them or press the mic):
- "Hey Solaris, open Steam", "Hey Solaris, open Opera GX", "Hey Solaris, open Settings"
- "Hey Solaris, open the accessibility section" / wallpaper / music / theme / "go home"
- "Hey Solaris, pause the wallpaper", "Hey Solaris, play the wallpaper", "Hey Solaris, next wallpaper"
- "Hey Solaris, pause the music", "Hey Solaris, next song", "Hey Solaris, previous song", "Hey Solaris, what's playing", "Hey Solaris, volume up"
- "Hey Solaris, change theme to red"
- "Hey Solaris, how is my PC doing"
- "Hey Solaris, what is on my screen?" (or press the eye button first)

Problems? Look at the black window that stays open: it prints what went wrong.
