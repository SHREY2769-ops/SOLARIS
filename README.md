# JARVIS: your personal AI assistant

Double-click `start_jarvis.bat` to run it. The first time, it sets itself up and opens a
settings file: paste your free Gemini key after `GEMINI_API_KEY=`, save, close.

Voice commands you can try (type them or press the mic):
- "open Steam", "open Opera GX", "open Settings"
- "open the accessibility section" / wallpaper / music / theme / "go home"
- "pause the wallpaper", "play the wallpaper", "next wallpaper"
- "pause the music", "next song", "previous song", "what's playing", "volume up"
- "change theme to red"
- "how is my PC doing"
- "what is on my screen?" (or press the eye button first)

Problems? Look at the black window that stays open: it prints what went wrong.
